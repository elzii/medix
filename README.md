## 🚀 Getting Started

1. 🔻 Download the latest release: <a href="https://github.com/elzii/medix/releases/download/latest/Medix-macos-arm64.zip" alt="Medix">Medix-macos-arm64.zip</a> 
2. ⚠️ If there my Developer cert has expired, the app will fuss. To work around it, bypass Gatekeeper with the following commands:


```sh
sudo xattr -cr /path/to/app/or/dmg
codesign --force --deep --sign - /path/to/app/or/dmg
```
